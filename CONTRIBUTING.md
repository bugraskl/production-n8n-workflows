# Contributing

Useful fixes and production-tested workflows are welcome.

1. Remove credentials, personal URLs, email addresses, and real payloads.
2. Add one workflow JSON file under `workflows/` and a matching guide under `docs/`.
3. Keep configuration in a clearly named `Config` node.
4. Include failure behavior, retry behavior, and a safe first-run explanation.
5. Run `npm test` before opening a pull request.

Please do not submit scraped workflow dumps or AI-generated collections that were not reviewed and tested.
